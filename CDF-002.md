## Data format

This CDF defines new MIME Type `cdf`.

MIME type `cdf` is not registered with IANA. It is intended for use in NDEF records.

## Motivation
In order to communicate over web technologies or similar we need MIME type. For easier payload parsing we introduce major mime type `cdf`. 
Usage with minor types is defined in [CDF 003](/CDF-003.md).
