## Motivation
In order to distinguish CDF payloads from other data (e.g. in NDEF records) we need MIME type. For easier payload parsing we introduce major mime type `cdf`.
Usage with minor types is defined in [CDF 003](/CDF-003.md).

## Data format

This CDF defines new top-level MIME type `cdf`. Full type has form `cdf/<minor>`, minor types are defined in [CDF 003](/CDF-003.md).

MIME type `cdf` is not registered with IANA. It is intended for use in NDEF records.

- Generator MUST write type in lowercase.
- Reader MUST compare type case-insensitively.

### Forward compatibility

- Reader MUST ignore unknown minor types.
- Incompatible changes MUST introduce a new minor type.
